# 🐍 Estudos de Python

Repositório com os projetos práticos que desenvolvo enquanto estudo Python, rumo à área de dados.

Cada projeto fica em uma pasta própria, com o código, um `README.md` explicando como funciona e imagens do programa em execução.

## 📁 Projetos

| # | Projeto | Descrição | Conceitos |
| --- | --- | --- | --- |
| 01 | [Calculador de Prazos](calculador_de_prazos) | Recebe uma lista de tarefas, classifica cada uma como concluída, em dia, urgente ou atrasada e mostra um resumo no final. | variáveis, booleanos, operadores, `while`, `for`, `if`/`elif`/`else`, f-strings |

## 🚀 Como executar um projeto

Com o Python 3 instalado, entre na pasta do projeto e rode o script:

```bash
cd calculador_de_prazos
python calculador_de_prazos.py
```

## 🛠️ Tecnologias

- Python 3 (sem bibliotecas externas, por enquanto)
- Git e GitHub
